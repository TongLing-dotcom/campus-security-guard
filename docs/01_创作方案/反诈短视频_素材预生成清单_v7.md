## 三、"合理插入"三条总则

### 1. 三种插入形态，按信息量选
| 形态 | 适用 | 用法 |
|---|---|---|
| **全屏插入** | 需要观众看清内容时（来电、预警弹窗） | 直接铺满，前后各留 0.2s 缓冲；时长 0.5–2s |
| **画中画 PiP** | 主角反应是主画面、UI 只作辅助（转账、回拨） | 缩到角落约 30% 宽，加圆角 8px + 轻阴影，模拟"手机悬浮" |
| **分屏** | 需要同屏对比/揭露（镜2、镜4） | 左右各半屏，**两条素材必须同机位、同景别**才能无缝拼 |

### 2. 时机：卡在情绪节拍上
- 来电界面 → 卡在**铃声响起**的第一拍；
- 转账界面 → 卡在**主角手指悬停**那一刻；
- 预警横幅/弹窗 → 卡在**手指将按未按**的瞬间（打断感最强）；
- 回拨界面 → 卡在**挂断后拿起手机**的动作上。
- **对帧**：插入点的画面动作要与 UI 的进出严格对齐，差 2–3 帧就会"假"。

### 3. 动效与音画
- 入场：UI 用**滑入 / 淡入 + 轻微放大**（3–6 帧），别硬切；
- 出场：**淡出**，或随镜头运动带出；
- 音画同步：UI 出现的**同帧**起音效（铃声 / 提示音 / 挂断音）；
- 画质统一：所有素材统一**超分到 1080P**、统一调色（冷蓝基调），避免画中画"像贴纸"。

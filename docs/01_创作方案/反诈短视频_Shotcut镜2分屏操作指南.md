## 四、方案 B：预裁素材法（最省事、零变形，推荐）

**已经在项目里备好了两条裁好的 960×1080 素材，直接摆位即可，不用碰遮罩。**

### 步骤 1 · 铺轨道
| 轨道 | 放什么 |
|:---:|---|
| **V2** | `镜2右屏_骗子_960x1080_8s.mp4` |
| **V1** | `镜2左屏_男主_960x1080_8s.mp4` |

两条都从 00:00 开始，长度均为 8.04s。

### 步骤 2 · 摆位（各加一个滤镜）

本版 Shotcut 26.9 的「尺寸、位置与旋转」面板结构是：

```
位置  [ 480 ] , [  0 ]      ← 两个格子：X , Y（单位：像素）
大小  [ 960 ] x [ 1080 ]    ← 两个格子：宽 x 高（单位：像素）
缩放  [ 100 % ]
尺寸模式  ○适合(Fit)  ○填充(Fill)  ○失真(Distort)
```

**「位置」的 X / Y 是矩形左上角在项目画面里的像素坐标**（左上角为 0,0），
不是"相对中心的百分比偏移"。项目 1920×1080 ＋ 素材 960×1080 → 加完滤镜默认就是居中，
显示为 **X=480**、Y=0、大小 960x1080、缩放 100%。所以**只需要改 X 这一个数**：

| 轨道 | 素材 | 位置 X | 位置 Y | 大小 | 缩放 | 尺寸模式 |
|:---:|---|:---:|:---:|:---:|:---:|:---:|
| **V1** | `镜2左屏_男主_960x1080_8s.mp4` | **0** | 0 | 960 x 1080 | 100 % | 适合(Fit) |
| **V2** | `镜2右屏_骗子_960x1080_8s.mp4` | **960** | 0 | 960 x 1080 | 100 % | 适合(Fit) |

> **取值原理（已实测验证）**：X 是矩形左边缘坐标，项目宽 1920。
> - X = **0** → 占 0–959 列 → **左半屏** ✓
> - X = **960** → 占 960–1919 列 → **右半屏** ✓
> - X = 480（默认）→ 占 480–1439 列 → 居中
>
> ⚠️ 早期版本或网上教程常写「水平 −25%」或「−480」，那是**另一套（绝对偏移/百分比）口径**，
> 在本版里会把画面推出画外（−480 时画面只剩右半边露在屏幕左侧，构图就废了）。

> **如果你是拿原始 1920×1080 素材**（`镜2骗子全.mp4` 等）：它们默认就铺满整屏，
> 改「位置」没用，得先缩小再裁 —— 这条路线不划算。**用预裁的 960×1080 素材（方案 B），
> 或走方案 A 的遮罩法。**

## 六、水印处理（重点，已实测）

### 6.1 现状

| 素材 | 水印位置 | 形态 |
|---|---|---|
| `镜2左屏_男主_960x1080_8s.mp4` | **左下角** | **镜像字**（源素材本身被水平翻转所致） |
| `镜2右屏_骗子_960x1080_8s.mp4` | **右下角** | 正常字 |

实测包围盒（各自 960×1080 素材自身坐标系，格式 x y w h）：

| 素材 | x | y | w | h |
|---|:--:|:--:|:--:|:--:|
| 左屏 | 0 | 1014 | 233 | 69 |
| 右屏 | 731 | 1019 | 215 | 48 |

> 全片规律：**所有 AI 生成素材的水印都在右下角同一位置**（1920×1080 素材为 `x1699 y1027 w199 h32`）。
> 左屏那条之所以跑到左下角且镜像，是因为该源素材被水平翻转了。采样图见
> `02_生成视频/全片素材水印分布_采样.png`。

### 6.2 方案① 真去水印：Shotcut「斑点移除」（Spot Remover）✅ 推荐

滤镜名 **「斑点移除」**（英文 Spot Remover），在「滤镜 → 视频」里搜 `spot` 或 `watermark` 就能找到
—— 它的官方关键字里就带着 `delogo / watermark / clean`，是专门为**去台标/去水印**设计的。

**原理**：不是模糊、也不是遮挡，而是**用矩形外侧最近的像素做插值填充**。对水印落在暗色/平滑背景上的
情况效果几乎无痕 —— 镜2 两条素材都是暗调，正好合适。

**操作（两条素材各做一次）**

1. 在时间轴上选中那条片段 → 右侧「滤镜」→ **＋** → **斑点移除**
2. 这个滤镜只有两组参数：

```
位置  [ X ] , [ Y ]
大小  [ W ] x [ H ]
```

3. **最省事的做法：直接在预览窗口里拖框。** Shotcut 会为这个滤镜在预览上画出**可拖动的矩形**，
   把框拖到水印上、拉到刚好包住水印即可 —— **这样完全不用管坐标系。**
4. 想填数值的话，按下面选一组。

**路线 A：用预裁的 960×1080 素材（方案 B 那条路线）**

这里有个**关键坑**：坐标**不是素材自身的 960 坐标**，而是**项目 1920×1080 的坐标**。
因为 Shotcut 里时间轴片段的滤镜，作用在"被居中放进项目画布之后"的画面上 —— 960 宽的素材默认居中在
x = 480，所以水印坐标要 **+480**。已用 melt 实测：填 `733` 水印**还在**，填 `1213` 才抹掉。

| 轨道 | 素材 | 位置 X , Y | 大小 W x H |
|:--:|---|:--:|:--:|
| **V1** | 镜2左屏_男主 | **480 , 1014** | **233 x 69** |
| **V2** | 镜2右屏_骗子 | **1211 , 1019** | **215 x 48** |

**路线 B：用原始 1920×1080 素材（方案 A 遮罩法那条路线）**

改成按源坐标直接量（左屏源素材的镜像水印在 1920 帧里同样是左下角）：

| 轨道 | 素材 | 位置 X , Y | 大小 W x H |
|:--:|---|:--:|:--:|
| V1 | `镜2后半段_左半屏_男主全_8s…mp4` | **4 , 1024** | **217 x 53** |
| V2 | `镜2骗子全.mp4` | **1699 , 1028** | **199 x 31** |

**⚠️ 滤镜顺序会改变坐标**（因为位置变了，水印也跟着走）：

| 「斑点移除」放在 | V1 左屏 | V2 右屏 |
|---|:--:|:--:|
| 「尺寸、位置与旋转」**上方**（先执行） | 480 , 1014 / 233x69 | 1211 , 1019 / 215x48 |
| 「尺寸、位置与旋转」**下方**（后执行，画面已在左右半边） | **0 , 1014** / 233x69 | **1691 , 1019** / 215x48 |

> 拿不准就用第 3 步的**拖框法**，顺序随便放都行。
> 效果验证图：`02_生成视频/shot02_v9/镜2分屏_水印去除_实测验证.png`（拍摄自 melt 实际渲染输出，×5 放大看无痕）。

### 6.3 方案② 压黑条（省事，但会留痕）

- 用「文件 → 打开其它 → **彩色/Color**」生成一个黑色源，拖到 **V3** 轨铺满 8.04s
- 加「尺寸、位置与旋转」：大小 **1920 x 64**、位置 **X = 0 , Y = 1016**
- 一次盖掉左右两个水印；代价是底部约 6% 画面被压掉（短视频常见做法，几乎无感）

### 6.4 方案③ 裁剪（不推荐）

「裁剪：矩形」裁掉底部 64px → 画面变 1920×1016，拉回 1080 会整体变形，不拉就留黑边。
**效果不如方案②，别走这条。**

### 6.5 ⚠️ 合规提醒（务必先看）

抹掉平台的「视频由AI生成」标识，本质是**移除生成合成内容标识**。按《人工智能生成合成内容标识办法》
（2025-09-01 施行），任何组织和个人**不得恶意删除、篡改、伪造、隐匿**生成合成内容标识；
参赛、公开展播场景的风险更高。

建议按这个优先级：

1. **保留水印** + 片尾加「本作品由AI辅助制作」声明 —— 最稳，且与本章方案①并列不冲突；
2. 若因构图必须处理（例如左屏那个**镜像字**看着像画面故障），**先确认参赛规则**是否允许，风险自担；
3. **不要**把水印"搬"到画面别的位置 —— 那是篡改标识，性质比移除更重。

## 九、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 人物被横向压扁 | 用了「尺寸模式：失真/变形」或直接改了宽高 | 改回 **适合（Fit）** 或遮罩法 |
| 画面上下有大黑边 | 尺寸模式用了"适合"但素材是 16:9 且被缩小 | 方案 B 用的是 960×1080 素材，不应出现；检查是否误用原始 1920×1080 素材 |
| 只剩半张脸、构图太紧 | 误用了"放大裁切"（尺寸 200%）路线 | 改用本指南方案 A/B（均为零缩放） |
| 一条画面被另一条全盖住 | 遮罩没生效 / 遮罩位置错 | 按方案 A 步骤 4 排查 |
| 项目分辨率变成 1924×1076 | 用了"自动"视频模式 | 「设置 → 视频模式」手动改回 1920×1080 24fps |
| 「位置」里只有像素、找不到百分比 | 本版 Shotcut 的「位置」就是像素坐标（X,Y＝矩形左上角），这是设计如此 | 直接填 **X=0 / X=960**，别去找 % |
| 填了 −480 或 ±25% 后画面跑到画外 | 套用了旧的"偏移/百分比"口径 | 位置 X 改回 **0**（左屏）/ **960**（右屏），Y 保持 0 |
| 导出的画面有一条细黑缝 | 中缝线未叠加、或两条素材边界未完全贴齐 | 叠 `15_分屏中缝_4px白线_透明.png` 盖住接缝 |
| 找不到「斑点移除」滤镜 | 搜索词不对 | 滤镜搜索框里输 `spot`，或直接翻「视频」分类（英文版叫 Spot Remover） |
| 「斑点移除」填了坐标水印还在 | 坐标系搞错了：填的是素材坐标，但滤镜要的是项目坐标 | 按 6.2 的表把 X 加 480（或直接用预览上拖框） |
| 「斑点移除」把画面弄出一块糊斑 | 框拉得比水印大太多，插值跨到了明暗交界或纹理区 | 把框缩到刚好包住文字（外扩 4–8px 即可），别贪大 |
| 处理后水印位置"跑"了 / 又出现了 | 「斑点移除」与「尺寸、位置与旋转」的前后顺序变了 | 按 6.2 表格对号入座，或把滤镜拖到列表最下方后重新拖框 |

## 十一、两条画面怎么"合并"成一条素材

**结论先说：Shotcut 没有跨轨"合并/Join"命令。** 画面是在**预览和导出时自动合成**的 ——
V1（左）与 V2（右）各占一半、互不遮挡，你在预览窗口看到的就是最终成品，**不需要任何"合并"操作**。

要把这 8 秒分屏变成**一条可复用的素材**，路线是「**导出 → 重新导入**」：

### 情形 1｜这个工程只做镜2 分屏（推荐）
1. 确认时间轴只有这一段、总长 8.04s
2. 「文件」→「导出视频」（**Ctrl+E**），或点右侧「导出」标签
3. 预设选 **H.264**，若输出目录没有就新建 `06_导出成片/_parts/`，点「导出文件」，存为
   `06_导出成片/_parts/镜2后半段_分屏.mp4`
4. 导出完成后，「文件 → 打开文件」把这个 mp4 加进播放列表 —— **它就是一条普通素材**，
   可以直接拖进整片工程，位置、滤镜、时长都按单条素材处理

### 情形 2｜镜2 和别的镜头在同一个时间轴上
只导镜2 这一段，用**区间标记（Range Marker）**：
1. 播放头移到 8s 区段开头 → 按 **M** 加一个标记
2. 按住 **Ctrl 拖动**标记右边缘拉到区段结尾（或右键标记 →「编辑」→ 直接填结束时间），
   得到一个"区间标记"
3. 右侧「导出」面板 → **「From（来源）」下拉菜单** → 选中你这个区间标记的名字
4. 点「导出文件」→ 只会渲染这一段

> 备选路线（同样可用）：时间轴菜单 →「复制时间轴到源」（**Ctrl+Alt+C**）→ 在「源」播放器里用
> **I / O** 标出入点、出点 → 导出面板 From 选「**Source / 源**」。

### 想让它"像一个整体"那样操作
- **Ctrl+G 编组**：两条片段一起移动、一起删除（注意：这只是编组，**不会真的变成一条**）
- **Shift+S（分割所有轨道）**：在播放头处把 V1/V2 同时切开 —— 切点永远对齐，
  之后分屏段就能像普通镜头一样被裁剪、移位、加转场

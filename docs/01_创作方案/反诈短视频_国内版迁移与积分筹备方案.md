# 反诈短视频 · 国内版迁移评估与积分筹备方案

> 决策背景：国际版积分余额告急，拟转战 WorkBuddy 国内版承接《真假妈妈》反诈短视频的 AI 画面生成。
> 撰写日期：2026-10-02

---

## 一、结论先行

| 问题 | 结论 |
| :--- | :--- |
| 国内版能不能接住这个项目？ | **能，而且适配度不低。** 本项目刻意规避了真实人脸、大量使用风格化/抽象/首尾帧过渡，正好落在国产视频模型（Seedance / 可灵系）的强项区间 |
| 质量会比国际版差多少？ | **抽象/特效/风格化镜头：基本持平。** 真实人物微表情、电影级写实运镜：**略弱一档**。本项目几乎不碰后者 |
| 成本大概多少？ | 本项目需 AI 生成的约 **41 秒 / 9~10 次调用**，单轮约 **500~1,100 积分**，含 3 轮迭代约 **1,500~3,300 积分** |
| 该买哪档？ | 体验版（500/月）**不够跑完整项目**；建议 **标准版 ¥70/月（4,000 积分）**，宽裕则高级版 |
| 积分能提前囤吗？ | **囤不住。** 积分按月发放、当月有效不结转，只能"提前铺渠道 + 卡准时间点"，不能长期攒 |

## 二、国内版 vs 国际版：视频生成能力对比

| 维度 | 国内版 | 国际版 | 对本项目的影响 |
| :--- | :--- | :--- | :--- |
| 可调用视频模型 | 国产为主：Seedance（即梦/字节）、可灵（快手）、Vidu、混元系 | 覆盖面更广，可及 Google Veo / Sora / Runway 等 | **影响有限**。本项目不需要 Veo 级写实能力 |
| 中文提示词理解 | **明显更强**，中文语义、国潮/反诈语境吃得准 | 中文提示词需转英文，易丢细节 | **利好**。分镜提示词可直接用中文迭代 |
| 首尾帧控制 | **支持**（首帧图 + 尾帧图锁定中间过程） | 支持 | **利好**。镜1、镜3 正是靠首尾帧落地 |
| 人物一致性 | 靠参考图（可灵系较强） | 靠参考图 + 部分模型原生一致性更强 | **中性偏弱**。镜4/镜8 需同一参考图 + 后期调色兜底 |
| 写实人脸 | 受限、需规避 | 相对宽松 | **中性**。本项目合规要求本就禁止逼真人脸 |
| **中国生活场景还原** | **明显更强**，中式宿舍/上下铺/室内陈设训练充分 | 需大量提示词约束，容易出"欧美感"宿舍 | **利好，且是本次迁移的最大意外收获**。v4 镜1 是宿舍实景，国产模型几乎不会翻车 |
| 单条时长 | 部分模型支持 4~30 秒可调 | 普遍 5~10 秒 | **利好**。8~10 秒镜头可一次成型 |
| 分辨率 / 画幅 | 480P / 720P / 1080P；16:9 / 9:16 / 1:1 | 同类 | 持平 |
| 音频 | 默认生成音效/配音，可关闭 | 同类 | 持平 |
| 生成耗时 | 单条约 1~3 分钟 | 同类 | 持平 |

**一句话**：国际版的优势在"模型货架更全、写实天花板更高"；国内版的优势在"中文语义准、首尾帧/时长控制实用、合规尺度天然贴合反诈题材"。**你这个项目的题材和做法，把国际版的优势让掉了，把国内版的优势全用上了。**

## 三、质量预估：逐镜适配度

按《真假妈妈》**分镜工程表 v4**（8 镜 · 59s）逐条对照国内版能力：

| 镜号 | 时间码 | 时长 | 画面（v4） | 国内版适配度 | 预估质量 | 说明 |
| :-: | :-: | :-: | :--- | :--- | :--- | :--- |
| 1 | 0:00–0:03 | 3s | 宿舍实景 → 陌生来电 → 接通见"妈妈"面容 → **穿透入屏**进代码隧道 | ★★★☆☆ | 中偏上 | 宿舍实景是国产模型强项；**"穿透入屏"是过渡特效，属通用弱项**。必须按 v4 建议拆两段生成（实景段 + 隧道段），剪映叠化衔接 |
| 2 | 0:03–0:11 | 8s | 代码隧道中代码流汇聚 → 凝结成半透明面具雏形 | ★★★★★ | 优 | 抽象粒子/形变是 Seedance 系看家本领，中文提示词一步到位 |
| 3 | 0:11–0:21 | 10s | 面具下降 → 贴合无脸人偶 → 锁死 → 切视频通话 | ★★★★★ | 优 | 首尾帧锁定 + 无脸人偶设定，完美规避五官崩坏；10s 需模型支持长时长（Seedance 系可到 30s） |
| 4 | 0:21–0:27 | 6s | 4a 面部特写皱眉 / 4b 手指悬停颤抖 | ★★★☆☆ | 中 | 微表情细腻度是国产模型相对弱项；靠"非可识别形象 + 短切 + 冷色调"稀释 |
| 5 | 0:27–0:34 | 7s | 预警弹窗 → 转账中断 → 假脸**碎裂成像素** → 空白 | ★★★☆☆ | 中 | 国内版**没有** Pika 那种一键 Explode；建议 AI 只出静态崩散帧，碎裂动画交剪映粒子层 |
| 6 | 0:34–0:44 | 10s | 三块图标面板依次动效出现 | — | — | 纯 Motion Graphics，**不走 AI 视频**，剪映做（风格一致性 AI 保证不了） |
| 7 | 0:44–0:52 | 8s | 防骗口诀逐行弹出 | — | — | 文字动画，**不走 AI 视频**，剪映做 |
| 8 | 0:52–0:59 | 7s | 挂断 → 回拨真"妈妈" → 模糊 → 主题字定格 | ★★★★☆ | 良 | 用镜1/镜4 同一参考图保一致性；模糊/暖色过渡交剪映 |

**汇总**：8 镜中 **6 镜走 AI 视频（合计 41 秒）**，2 镜（18 秒）由剪映纯后期完成。

**质量结论**：
- **v4 把镜头往"实景 + 因果叙事"方向改，反而更利好国内版**——宿舍、上下铺、中式室内这类场景，国产模型训练数据充足，还原度大概率**优于**国际版。
- 整体观感与国际版**差距很小**；风险集中在三处：镜1 的"穿透"过渡、镜4 的微表情、镜5 的碎裂特效。
- 这三处恰好都有成熟的后路：**镜1 拆两段叠化、镜4 短切稀释、镜5 交剪映**。

**降低风险的三条实操**：
1. **镜1 必须拆两段**：实景段（宿舍 + 男生 + 手机）单独生成，代码隧道段单独生成，剪映叠化 + 加速做"穿透感"。别指望一次生成出穿越效果。
2. **镜1/镜4/镜8 共用同一张参考图**：提前用文生图定一张"非可识别男大学生"参考图，三镜共用，否则人物会跳脸。
3. **全片统一冷色调打底**：用调色把不同模型、不同镜次的色差抹平；镜8 再往暖色过渡。

## 四、积分成本测算

**计价口径**：视频生成按次计费，**5 秒约 50~100 积分**（分辨率、模型等级、时长不同会有浮动，实际以生成前提示为准）。

按 v4 分镜的实际**生成次数**（不是时长）测算：

| 镜头 | 调用次数 | 单轮消耗 |
| :--- | :--- | :--- |
| 镜1 3s（拆实景段 + 隧道段） | 2 | 100~200 |
| 镜2 8s | 1 | 100~200 |
| 镜3 10s | 1 | 100~200 |
| 镜4 6s（4a + 4b 两段） | 2 | 100~200 |
| 镜5 7s（或改剪映做，0） | 1 | 0~100 |
| 镜8 7s（拨打 + 通话两段） | 2 | 100~200 |
| **AI 生成小计** | **约 9~10 次** | **500~1,100** |
| **含 3 轮迭代** | ×3 | **1,500~3,300** |

> 注1：镜6、镜7（共 18 秒）由剪映纯后期完成，**不消耗积分**。
> 注2：镜5 若完全交剪映粒子层，可省下约 100/轮。

**套餐匹配建议**

| 套餐 | 月积分 | 能否跑完本项目（含迭代） | 建议 |
| :--- | :--- | :--- | :--- |
| 体验版（限时免费） | 500 | ✗ 约半轮 | 只够试拍 2~3 个镜头 |
| **标准版 ¥70/月** | 2,000 + 2,000 = 4,000 | ✓ 够一次完整 + 充分迭代 | **推荐** |
| 高级版 ¥140/月 | 4,000 + 5,000 = 9,000 | ✓ 可同时开 2~3 个项目 | 若还要做系列片 |
| 旗舰版 ¥700/月 | 20,000 + 30,000 = 50,000 | ✓ 团队批量 | 个人不必 |

**省积分的两个关键动作（重要）**
1. **别用 Auto 模型调度**：系统自动挑"最优"模型，往往"最优≠最便宜"，消耗可能高出数十倍。日常任务手动选免费模型（如混元 HY3），重活再切低成本模型（如 DeepSeek V4-flash，消耗约 0.06 倍）。
2. **先出低分辨率小样**：先用 480P 试画面方向，方向确认后再出 1080P 终稿，能砍掉大量废片消耗。

## 六、风险与注意事项

1. **积分不能长期囤**：按月发放、当月有效、不累积结转（加赠积分自到账起 1 个月内有效）。"提前赚积分"的正解是**提前铺好渠道、卡准月末/月初的发放节奏**，而不是攒一大笔放着。
2. **视频生成是独立计费项**：与普通对话积分分开计，单次 5 秒 50~100 积分，长片成本会线性放大——**务必先做分镜、先出小样**，别边想边拍。
3. **"穿透入屏"是通用弱项，别硬刚**：镜1 的穿透过渡国内外模型都做不好，必须拆两段生成 + 剪映叠化，靠后期造"穿透感"。
4. **人物一致性仍是最大不确定项**：镜1/镜4/镜8 三镜必须共用同一张"非可识别男大学生"参考图，且后期统一调色，否则会跳脸。
5. **文字不要交给 AI 生成**：96110 号码、防骗口诀等关键文字一律用剪映文字层合成，AI 生成文字不可靠。
6. **合规红线不变**：禁用逼真人脸、不出现真实平台 Logo 与界面、预警文案不写完整诈骗话术。
7. **活动条款以官方页面为准**：本方案的邀请奖励与套餐价格引自官方页面（2026-10-02 抓取），实际额度、有效期可能调整，注册前请在活动页再确认一次。

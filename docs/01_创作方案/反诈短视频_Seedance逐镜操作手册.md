## 二、通用参数设置（所有镜头统一）

### 1. 视频比例（画幅）

```
选择：9:16（竖屏）
```

**理由**：短视频征集作品，竖屏 9:16 是抖音/快手/视频号的标准比例。全片统一竖屏。

### 2. 分辨率

```
测试阶段：540P 或 720P（省积分，快速看效果）
定稿阶段：720P（国内版当前主要档位）
```

**注意**：国内版Seedance 2.0主要支持480P/720P，暂不支持4K。720P在剪映中做"画质修复/超分"后可提升到接近1080P观感，足够参赛使用。

### 3. 生成时长

Seedance单次最长15秒。各镜头需要分段策略：

|  镜号 | 需要时长 |   单次生成  | 分段策略       |
| :-: | :--: | :-----: | ---------- |
|  镜1 |  4s  | 单条 4s | 一条生成（v7 已取消段B，不再分段） |
|  镜2 | 13s  | 左半 7s + 右半 7s（各自生成） | **分屏**：左右各生成一条独立素材，剪映半屏并置 |
|  镜3 |  8s  | 4s + 4s | 分2段生成（采集段 + 合成段），剪映拼接 |

### 4. 模型版本

```
选择：Seedance 2.0 标准版（不用Fast极速版）
```

**理由**：标准版细节最丰富、控制最精准。Fast版速度快3倍但画质降级，适合高峰期排队时应急。

### 5. 高级设置参数（生成偏好）

> **位置**：提示词输入框下方 → 「高级设置」折叠菜单 → 点开

| 参数名（界面实际名称） | 范围 | 镜1 / 镜2（人物） | 镜3（界面） | 说明 |
|---|---|---|---|---|
| **风格强度** | 0-100 | **75** | **70** | 越高越严格遵循提示词/首尾帧；越低AI越自由发挥 |
| **动态幅度** | 0-50 | 镜1:**12** / 镜2:15 | **25** | 控制动作幅度；**镜1 要极低**（微表情必须克制），镜2 人物动作克制=15，镜3 界面动效=25 |
| **画面一致性** | 0-100 | **88** | **85** | 图生视频/首尾帧专用，越高越贴近原图 |
| **去模糊优化** | 开/关 | 开启 | 开启 | 自动优化画面锐度，建议必开 |
| **种子值** (Seed) | 数字 | 固定 | 固定 | 首次满意后复制Seed值，后续同系列镜头复用保证一致 |

> **v8 改版说明（三条硬约束）**：
> 1. **取消整屏模糊**：片头信息改为 0:00–0:02 叠加（淡入 0.2s／淡出 0.2s），画面**全程清晰**，2s 后手机屏内容必须看得清。

>
> **v8.1 时长**：**直接采用 AI 原片全长 5.0s（源 5.04s，120 帧 @24fps），不裁切、不重新生成**。总时长 60s。

#### ⚠️ 头号难点：视线锚定 + 微表情幅度控制

这是 v8 修改的核心，也是最容易翻车的两处。

**难点一：视线锚定手机屏幕（新增）**
- **根因**：模型容易把"低头看手机"演成"抬头看镜头"或"转头看向观众"，尤其在推近过程中。
- **对策**：
  1. 提示词**禁用"面向屏幕"这类歧义表达**，统一写"**低头看手中的手机屏幕**"；
  2. 负向提示词**必须包含**：`看镜头, 与镜头对视, 正脸面对观众, 转头看观众, 打破第四面墙`；
  3. 用**图生视频**锁首帧（低头看手机的侧前方构图），AI 自由度被首帧压住；
  4. 明确写"**镜头推近时人物头部和视线方向保持不变**"——告诉模型"动的是镜头，不是人"。

**难点二：微表情幅度控制**

| 常见翻车 | 根因 | 对策 |
|---|---|---|
| 主角瞪大眼、张嘴、身体后仰 | 视频模型默认把"看到亲人来电"演成惊喜/惊吓，情绪自动加码 | 负向写死 `夸张表情,惊讶瞪眼,张嘴,喊叫`；**同一提示词连出 4–6 条，挑最克制的一条** |
| 表情纹丝不动 | 负向写太狠，把微表情一起禁掉 | 只禁"夸张"，不要写"no expression"；保留"眉毛极轻抬起、眼睛微微睁大"的正面描述 |
| 眉毛抬得像挑眉 | 幅度不受控 | 用**图生视频**锁定首帧（平静侧脸）；动态幅度降到 **12** |
| 推近中抬头看镜头 | 模型把推近理解成"要求主体回应镜头" | 正向写"头部和视线方向始终不变"；负向加"转头看观众、正脸面对观众" |
| 推近过程中人脸变形 | 连续推近 + 侧脸，模型容易崩 | 动态幅度 **12**；生成 5s 只取 4s，掐掉尾帧 |

**兜底（最有效）**：若生成结果仍夸张，在剪映中把微表情那段**降速到 0.5×**，只保留起手前半段。慢放会显著削弱夸张感，成本几乎为零。

## 六、提示词写作要点

### Seedance 提示词万能公式

```
主体 + 动作 + 场景 + 光影 + 镜头语言 + 风格 + 画质 + 约束
```

### 本片三镜的约束词（必须加）

- `stylized` — 风格化
- `non-photorealistic` — 非照片级写实（镜3 界面）
- `no realistic human face` — 不生成逼真真人脸
- `no identifiable face` — 不出现可辨认真脸（镜1/镜2）
- `no recognizable face, only eyes visible` — 骗子只露眼睛、口罩遮脸（镜2 右半）
- `non-identifiable face, NOT a realistic deepfake` — 主角非可识别面孔、非深度伪造（镜1/镜2 左半）
- `stylized UI, no real software branding` — 界面风格化、无真实品牌（镜3）

### 反向提示词（否定词，填入"不需要的元素"框）

```
realistic human face, real person, identifiable person, 
deepfake, real social media interface, real platform logo,
blurry, deformed, distorted, flickering background
```

## 七、常见问题

**Q：720P够用吗？**  
A：够用。剪映有"画质修复"功能，可将720P素材超分到接近1080P观感。最终导出1080P即可。

**Q：生成效果不理想怎么办？**  
A：① 先用540P+3s快速测试提示词方向；② 满意后再用720P正式生成；③ 每镜保留2-3个备选版本，剪映中挑最好的。

**Q：积分不够怎么办？**  
A：每日免费60-100积分，三镜总计约40-49积分。如果一天做不完，分两天完成。也可完成新手任务获取额外积分（验证手机号+50，首次生成+50）。

**Q：首帧/尾帧图用即梦文生图生成，还是要自己画？**  
A：用即梦的"AI绘图"功能（文生图）直接生成。即梦的文生图和文生视频共用同一套账号积分体系。

**Q：要不要开Seedance自带音效？**  
A：本片不需要。音效/BGM全部从Pixabay下载CC0素材，在剪映中合成。Seedance生成的音效不可控且版权不明确。

## 一、发到 GitHub

**结论：可以发，而且和你参赛不冲突。** 官方通知里**未见"首发/独家/未公开发布"条款**（以你收到的通知原文为准），反而要求参与者在微博、抖音、B站等平台公开发布打卡。

### ★ 但发布前必须先做这件事：处理密钥

`08_配音/xfyun_config.json` **含讯飞明文密钥**（`appid` / `api_key` / `api_secret` / `api_password`），
该文件自己就写着「本文件含明文密钥。请勿上传公开仓库 / 外发」。

- **已为你创建 `.gitignore`**，其中已排除 `xfyun_config.json`、`.workbuddy/`、`__pycache__/` 与全部大体积媒体。
- **如果你曾经 push 过这个文件**（哪怕只有一次，哪怕后来删了）——GitHub 有专门的密钥爬虫，**几分钟内就会被扫到**。
  这种情况请立刻到讯飞控制台**重置 APIKey / APISecret**，并检查用量账单。
- 首次 `git init` 的话，`.gitignore` 已就位，直接 `git add .` 即可，密钥不会被跟踪。
- 建议额外建一个 `xfyun_config.example.json`（把值换成 `YOUR_APPID` 之类占位符）随仓库发布，方便别人复用脚本。

## 二、发到哔哩哔哩

**结论：选「视频投稿」。** 分区建议 **人工智能**（首选）或 **影视**。

### 为什么不是「短剧投稿」

- B 站**没有「AI 短剧」这个一级分区**。2025-03-07 起 B 站取消二级分区，现共 **36 个一级分区**，
  与本片相关的是：**人工智能**、**影视**、**小剧场**、**知识**、科技数码。
- 「短剧投稿 / 漫剧专区」是**合作通道**（如「**觉醒漫剧计划 2.0**」，要求上传完整 PV 或正片 **1–3 集**并带指定话题），
  定位是**系列剧集**，且需完成资质认证。
- 本片是**单集 56 秒**的科普短片，不是系列剧 → **走「视频投稿」入口**，不进短剧通道。

### 分区怎么选

| 分区 | 适合度 | 理由 |
| :-- | :-: | :-- |
| **人工智能** | ★★★ **首选** | 本片核心亮点是「AI 生成」；B 站 AI 区对 AI 短片接受度高，平台对 AI 内容有流量倾斜；与官方「鼓励使用 AI 创作」呼应 |
| **影视** | ★★☆ 备选 | 「短片」的天然归属；B 站 AI 创作大赛、觉醒漫剧计划均推荐投影视区 |
| **知识** | ★★☆ 备选 | 若更看重「反诈科普」属性，知识区用户对科普内容更友好 |
| 小剧场 | ★☆☆ | 偏情景喜剧/短剧演绎，与本片气质不完全贴合 |

### 投稿时的必做项

1. **开启「AI 生成内容标识」开关** —— 按《人工智能生成合成内容标识办法》（2025-09-01 施行），AI 生成内容必须显式标识。
   本片已在画面右下角常驻「视频由AI生成」＋ 片尾「本作品为AI辅助制作」＋ AI 徽标，**符合要求**，投稿时勾选即可。
2. **勾选「声明为原创」**（本片确为原创，非转载/混剪）。
3. **简介里写满 ≥10 字**，并加入话题。
4. **叠加比赛话题**：按通知要求，发布到 B 站时带 **#校园网络文明月#** 或 **#安全卫士#**，并 **@中国大学生在线** —— 这是活动的"网络宣传互动"环节，做了才算完整参与。
5. **标题/标签**建议围绕：`AI生成`、`反诈`、`国家安全教育`、`校园网络文明月`、`AI短片`。
6. 封面：1920×1080 / JPG 或 PNG / ≤5 MB（本片成片为 1920×1080，可直接截帧做封面）。

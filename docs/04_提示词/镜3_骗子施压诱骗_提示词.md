## 五、剪辑处理要点

1. **成片结构（6s）**：
   - **0–1s**：后期自行裁剪一个片段补入（作为镜3 开场，承接镜2→镜3）。
   - **1–6s**：本文件生成的 5s 素材。
   - ⚠️ **衔接点务必对齐**：补入片段**末帧** 与 生成素材**首帧**（= 镜2 骗子尾帧画面）应**构图一致**，否则接点会跳。建议补入片段就用**镜2 骗子素材的尾段**（静止或极轻微动作）。
2. **首尾衔接（镜2 → 镜3）**：镜2 右半屏骗子素材的**最后一帧 = 本镜第一帧**，**硬切即可**（无跳变）；如需更柔用 2–3 帧叠化。
3. **末帧利用**：生成素材 5s 处＝"诱骗说完、闭嘴盯屏"，**是一段自然收尾**——若你要把镜3 做够 6s 且不想补前 1s，也可**直接把末帧定格延伸 1s** 接在尾部（两种做法二选一，别同时用）。
4. **字幕**：在剪映叠加 **2 句骗子台词字幕**，每行 ≤15 字：
   - `小宇，你爸进医院了，妈急死了。`
   - `别声张，妈只能靠你了。`
   - 旁白"这声"妈"是假的。"**不叠字幕**。
5. **音效与 BGM**：键盘轻敲声 + 调音台推子声 + 波形"滋滋"底噪 + drone BGM（压迫感）；旁白落在补入的 0–1s 段。
6. **屏幕区**：如需信息感，由剪映在屏幕区**极轻叠一个抽象波形动效**，**不加任何文字标签**。
7. **转场**：镜3 → 镜4 用**硬切**。

## 六、提示词要点说明

1. **本轮最大的变化是运镜**：上一版是"波形微距 → 拉出到中景"，本轮改为**"从尾帧画面开始、缓慢推近到侧脸"**——因为要去掉前 1s（微距开场），改由后期补片；**推近也更有压迫感，贴合"施压"的情绪**。
2. **"不出现正脸"是本镜的头号合规项**：正向里明确写"接近侧脸轮廓即停、不绕到正面"，负向里把"**转头露出正脸／侧脸转向镜头过多**"放在最前面（模型对负向前几条最敏感）。
3. **"缓慢推近"与"人物稳定"是两个要同时满足的约束**——这也是动态幅度给到 15 的原因：**运动量留给镜头，人物本体尽量不写大动作**（只有前倾、手指轻推、下巴开合）。
4. **0–0.5s 只做"起手"**：不写任何台词开口，让这句施压话与你的后期配音**从 0.5s 处对齐**；侧背影/侧脸的口型本身不清晰，**不要求逐字对齐**。
5. **末帧状态＝诱骗说完、闭嘴盯屏**：为后期裁剪与接镜4 都留了干净的手尾。
6. **合规锁死**：负向必含"**露出清晰正脸／摘下帽子／摘下耳麦／话筒离开嘴边／出现妈妈人脸／屏幕出现人脸／界面文字／进度条／计数**"；台词**不含金额、账号、"转账"字样与操作步骤**。
7. **算力**：v11 **全片只需生成这一条 5s**；镜4/5/6 沿用 v10 提示词，**无需重生成**。

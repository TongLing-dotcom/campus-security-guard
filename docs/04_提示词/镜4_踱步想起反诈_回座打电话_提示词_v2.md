## 七、提示词要点说明

1. **删 96110 之后，"转折"要靠什么撑？**——原版靠"96110 来电打断"制造外部转折；删掉后，转折必须**回到人物内部**：**踱步越想越急 → 忽然停住 → 想起宣传里那句话 → 主动核实**。所以段 A 末尾那一拍"凝住"是本镜的**戏眼**，提示词里专门写了"先凝住、肩塌、轻吸一口气"这组动作。
2. **"想起反诈宣传"为什么不给闪回画面？**——用户选定**纯表演＋旁白**。这样**不打断表演的连贯性**，也不需要额外素材；同时在负向里写死"凭空出现文字／空中浮现文字／画面内弹窗"，**防止模型自作主张飘出一张海报**。
3. **"转身→踱步→回座"要有三个阶段的速度感**：段 A **急**（步子由慢到快）→ 段 B **沉**（扶桌沿、慢慢坐下）→ 段 C **定**（拿手机、拨号，动作平稳）。三段的**动态幅度 35→18→12** 就是照这个设计的。
4. **删掉"手抖缩回"之后，片尾对照的右半素材要换**（原取"缩手后抓起手机拨号的手"）：现在可改取**段 C 的"拿起手机拨号"**（右半·暖色，表示"多打一个电话"）；左半仍建议取**段 A 1–2s「放下手机、撑桌起身」的手部瞬间**（冷色）。
5. **与镜6 的重叠**：本镜末尾已经"举起手机等着接起"，原镜6 又是"举着手机听回铃音"——**建议把镜6 压缩成 2–3s 的回铃等待**，或整段并入本镜（见第五节）。

## 一、镜头意图

**放大"我只听到声音、并不认识这个号"的疑点。**
骗子用"妈妈"的声音先问一句"**小宇，是你吗？**"，男主回一句"**你谁呀？**"——**用一个最朴素的反问，把"陌生号＋熟悉声"这个矛盾点顶到观众眼前**，让后面镜2 后半段那句"**是妈妈啊！**"的自称更有分量。

- **0–2s**：骗子**画外音**（妈妈声线，**温柔、自然、带一点试探**）＝"小宇，是你吗？"；**画面只给男主**。
- **2–3s**：男主回话（**平淡、带一丝不认识这个号的疑惑/警惕**）＝"你谁呀？"

## 七、合规锁死项（★必守）

1. **只出现男主一人**；**不出现任何"妈妈"影像**（延续"只闻其声、不见其人"）。
2. 男主为**非可识别面孔**，**不看镜头、不面向观众**（首帧即侧后方，正向/负向双重锁死）。
3. 表演**克制、不夸张**（负向已锁"夸张表情/惊讶瞪眼/张嘴/喊叫/剧烈转头"）。
4. 台词"**小宇，是你吗？**""**你谁呀？**"**不含金额、账号、"转账"字样与任何操作步骤**。
5. 画面内**不出现任何文字、弹窗、UI**（负向已锁）。

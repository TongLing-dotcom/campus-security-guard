## 六、提示词要点说明

1. **首帧是坐姿、主题是踱步 → "起身"必须写进去**：这是本镜最容易被忽略的接点问题。若不写起身，模型会直接在站姿上起步，与首帧**跳变**。
2. **"不正对镜头"要在正负向双保险**：正向写"背对镜头、四分之三侧后方视角、只出现背影与侧脸、绝不转向镜头"；负向**首条**就是"看镜头／转头看镜头／正脸面对观众／脸部转正"。
3. **"来回踱步"要写"来回"和"两趟"**：只写"踱步"模型可能只走一趟就停；写"从书桌走向床铺、又折返回来、将近两趟"更容易出往返感。
4. **焦虑靠身体细节，不靠表情**：本镜**不给正脸**，所以情绪只能从**肩线紧绷、脖子前倾、手攥紧、按后颈、胸口起伏**这些**侧影/背影可读的身体语言**来传达——这也是提示词里大量写身体动作的原因。
5. **动态幅度必须调高到 35**：本镜是全片**唯一有大幅走位**的镜头（镜3/6 近乎静止）。给 12–15 会走不动。
6. **与镜5 的内容重叠问题（★重要，需你拍板）**：
   - **镜4（本镜，新）**：坐姿不安 → 起身 → **来回踱步** → 停住按后颈
   - **镜5（v10 原案）**：**从椅子起身 → 来回踱步** → 回座 → 96110 打断 → 缩手 → 回拨
   - 两者**都含"起身＋踱步"**，直接连着放会重复。
   - **三个可选方案**：
     | 方案 | 镜4 | 镜5 | 说明 |
     |---|---|---|---|
     | **A（推荐）** | 坐姿不安 → 起身 → **完整来回踱步** → 停住 | **删去开头"起身＋踱步"**，直接**从"踱步中停住/走回桌前"接起** → 回座 → 96110 → 缩手 → 回拨 | 情绪递进：先"走来走去"→ 再"被电话打断"；镜5 开头改为承接镜4 末帧 |
     | B | **只到"起身"**（5s：坐姿不安→起身→站住） | **保留完整"踱步→回座→…"** | 镜4 变成"起身过渡"，踱步仍归镜5 |
     | C | **不踱步**，只坐姿不安 | 不动 | 但这样就**不符合你"突出踱步"的要求** |
   - **本提示词按方案 A 编写**（镜4 含完整踱步）。**请确认选哪个，我再同步工程表与镜5 提示词。**

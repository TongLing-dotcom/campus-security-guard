## 五、重跑方法

```bash
cd "<PROJECT_ROOT>/06_导出成片"
PY="<TOOL_EXE>"
"$PY" _melt_字幕配音合成.py audio    # 混音轨（人声 + BGM + 铃声 + 闪避）
"$PY" _melt_字幕配音合成.py mlt      # 生成 Shotcut 工程
"$PY" _melt_字幕配音合成.py render   # 输出成片
```

> 只需改某一句台词时：改 `08_配音/配音台词表_v12.json` 的 `text` → 删掉对应 `08_配音/audio/<id>.mp3` → 用单句 cast 重配 → 重跑 `_gen_subtitles_v12.py` → 再走上面三步。

## 四、★ 剧本槽位体检：3 句塞不进

`speed` 取值范围 0–100（50 = 默认语速，100 ≈ 2 倍速）。用 `--autofit` 自动提速后：

| 台词 | 字数 | 剧本槽位 | 最快可达 | 结论 |
|---|:--:|:--:|:--:|---|
| `s04_02_旁白` 「钱还没转出去……重新打给妈妈。」 | 42 | **5.0s** | **7.06s** | ❌ **差 2.1s**，必须延长槽位或删字 |
| `s04_01_旁白` 「骗子只给你一个字——急。越急，越要停一下。」 | 16 | **2.0s** | **2.54s** | ❌ **差 0.5s** |
| `s02_07_男主` 「……真是您啊。妈，出什么事了？」 | 13 | **1.4s** | **1.56s** | ❌ **差 0.2s**（建议拆成两句分两次开口） |
| `s02_04/05_假妈妈` 「别怕。」「石头。」 | 2 | 0.80s | 0.82s | ⚠️ 超出 20ms，可忽略 |
| 其余 13 条 | — | — | — | ✅ 自动提速后全部塞进 |

**建议改法（不动画面，只放宽槽位）**——镜4 段A 的 **2–7s 是空的**（旁白只占 0–2s），完全放得下：

| 台词 | 原槽位 | 建议槽位 |
|---|---|---|
| `s04_01_旁白` | 0:24.0–0:26.0 | **0:24.0–0:26.6**（16 字 / 2.6s） |
| `s04_02_旁白` | 0:31.0–0:36.0 | **0:29.5–0:36.6**（42 字 / 7.1s，前移到 2–7s 空档里） |

改完把 `配音台词表_v12.json` 里对应的 `end` 改掉，重跑 `--cast` 即可。

> 根因：v12 工程表自己就标注了「⚠️ 两句语速均偏高（>5 字/秒）」。**中文超拟人在 speed=100 时上限约 8 字/秒**，剧本按 8.0–8.4 字/秒排的时间码，刚好越过物理上限。

## 五、★ 自己加台词（不在 v12 工程表里的对话）

不是所有对话都在 `配音台词表_v12.json` 里。自己加的走 **`自定义台词.json`**——菜单按 **11** 用记事本打开，或直接编辑该文件。

### 写法：往 `lines` 数组里加一个 `{...}` 就行

```json
{
  "id":   "自定义_01",
  "role": "男主",
  "tone": "疑惑",
  "text": "等等，[p500]你刚才说什么？",
  "start": 7.0,
  "end": 9.0
}
```

| 字段 | 必填 | 说明 |
|---|:--:|---|
| `id` | ✅ | 生成的文件名 → `audio/自定义_01.mp3`。**必须唯一** |
| `role` | | `旁白` / `男主` / `真妈妈` / `假妈妈` / `骗子`，决定用谁的声音 |
| `text` | ✅ | 台词正文，可含 `[p500]` 停顿 |
| `tone` | | 语气预设名（见第八节），如 `焦急`、`冷酷` |
| `start` / `end` | | **成片里的秒数**。不写就不做槽位检查、时间轴里 start=0 待你补 |
| `vcn`/`speed`/`pitch`/`volume` | | 单条覆盖，优先级最高 |

> JSON 不能写注释，所以文件里的说明都用了 `_` 开头的键名，程序会自动忽略。

### 合成

- 菜单按 **9** —— 只合成自定义台词
- 菜单按 **10** —— v12 台词表 + 自定义台词 一起合成
- 或命令行：

```bash
python xfyun_tts.py --cast 自定义台词.json --outdir audio --autofit
python xfyun_tts.py --cast 配音台词表_v12.json --cast 自定义台词.json --outdir audio --autofit
```

`audio/_manifest.json` 会**按 id 累加合并**——先合成 v12 再合成自定义，两次结果都在一份清单里，不会互相覆盖。然后按菜单 **5** 生成合并时间轴。

## 六、★ 调节语气与停顿（全部已实测，不是照抄文档）

### 1. 停顿：`[p500]`  —— 写在 text 里

在任意位置插入静音，单位毫秒。**实测数据**（同一句话）：

| 写法 | 实测时长 | 增量 |
|---|:--:|:--:|
| 无 | 4.20s | — |
| `小宇，[p300]你爸进医院了，[p300]妈急死了。` | 4.90s | **+0.70s** |
| `小宇，[p800]你爸进医院了，[p800]妈急死了。` | 5.88s | **+1.68s** |

用途：
- **卡口型**——演员嘴还在动、配音说完了，就在中间补 `[p300]`
- **凑槽位**——配音比 `end-start` 短，末尾补 `[p500]` 拉长
- **表演**——`别问了。[p800]按我说的做。` 中间那 0.8 秒冷场就是压迫感

> 逗号句号本身就会产生自然停顿，`[pN]` 是**在此之上再加**。全角 `［p500］` 也认。

### 2. 多音字：`着[=zhuo2]手`

指定前一个字的读音，声调写 1–5（1 阴平 2 阳平 3 上声 4 去声 5 轻声）。已实测生效。

### 3. 语气：`tone` 预设（14 档）

三个旋钮，**全部经 MD5 + 声学指标双重验证真实生效**：

| 旋钮 | 范围 | 实测结论 |
|---|---|---|
| **speed 语速** | 0–100 | 时长与语速成反比。30→5.23s，50→4.20s，70→3.02s，**100→2.02s**（正好 2 倍速）。**最强杠杆** |
| **pitch 语调** | 0–100 | 谱质心随 pitch **单调上升**：20→799Hz，35→918，50→1057，65→1160，**80→1407Hz**。越大越高越亮越年轻 |
| **volume 音量** | 0–100 | 响度**单调上升**：20→−29.2 dBFS，50→−23.0，80→−19.5，**100→−18.1**（符合文档"100=默认×2"） |

**用法**：命令行 `--tone 焦急`；台词表里 `{"tone":"焦急"}`。

| 名称 | speed | pitch | volume | 听感 |
|---|:--:|:--:|:--:|---|
| 平静 | 50 | 50 | 50 | 基准，无修饰 |
| 温柔 | 44 | 56 | 46 | 放慢、提调、收音量→亲切 |
| 亲切 | 48 | 54 | 50 | 略慢略高，日常对话 |
| 疑惑 | 46 | 60 | 48 | 略慢、提调、收音量→疑问感 |
| 焦急 | 78 | 62 | 60 | 大幅提速＋提调＋加音量→急 |
| 慌张 | 86 | 68 | 62 | 最快最亮最大声→失控 |
| 施压 | 60 | 36 | 56 | 压低调门、提音量→冷硬压迫 |
| 冷酷 | 52 | 32 | 52 | 压低沉、中速→无起伏 |
| 威胁 | 56 | 30 | 60 | 更低更响→凶 |
| 委屈 | 44 | 64 | 42 | 放慢、提调、压音量→哭腔 |
| 释然 | 42 | 46 | 44 | 放慢、压调、轻→松下来 |
| 激动 | 72 | 66 | 58 | 快、亮、响 |
| 低沉 | 44 | 32 | 48 | 慢、很低、偏轻 |
| 念白 | 42 | 50 | 48 | 慢而稳，旁白用 |

不满意可以在 `xfyun_config.json` 的 `tone_presets` 里改数值，或加自己的档位。

### 4. `oral_level` 与情绪音色（★2026-10-14 重大修正）

## 八、操作流程

### 步骤 0 · 自检

```bash
python verify_env.py --online
```

### 步骤 1 · 批量合成配音

```bash

```

输出 `audio/*.mp3` + `audio/_manifest.json`（含每条时长、占用槽位、是否超长、sid）。
终端会打印 **✅/⚠️/❌ 槽位体检表**。

单条试听 / 微调音色与语气：

```bash
python xfyun_tts.py --text "小宇，是你吗？[p300]" --out demo.mp3 --tone 温柔
python xfyun_tts.py --list-vcn      # 已授权音色 + 推荐选角
python xfyun_tts.py --list-tone     # 语气预设 + 停顿语法速查
```

### 步骤 2 · 生成 / 编辑时间轴

```bash
python mux_to_video.py template --cast 配音台词表_v12.json --cast 自定义台词.json --out 时间轴_v12.json
```

时间轴每条长这样，`start`/`end` 是**成片绝对秒数**，按成片实测口型微调：

```json
{ "id": "s03_02_骗子", "start": 19.5, "end": 22.0,
  "volume": 1.0, "file": "audio\\s03_02_骗子.mp3" }
```

### 步骤 3 · 配音入视频

```bash
# 多轨精确对位，保留原声并压到 12%

  --video "..\06_导出成片\真假妈妈_成片_v12_横屏1080p.mp4" ^
  --timeline 时间轴_v12.json --out "..\06_导出成片\真假妈妈_成片_v12_配音版.mp4" ^
  --keep-original --bg-volume 0.12
```

单条快速合成（验证用）：

```bash
python mux_to_video.py simple --video 某镜.mp4 --audio audio\s03_02_骗子.mp3 ^
  --out out.mp4 --mode mix --delay 1.5 --bg-volume 0.2
```

## 九、接口要点（备查）

### 鉴权（两种都已实测可用）

**方式一 · x-api-key**（配置里 `auth_mode: "apikey"`）

```
wss://cbm01.cn-huabei-1.xf-yun.com/v1/private/mcd9m97e6
Header: x-api-key: <APIPassword>     # 即控制台『鉴权信息·系统默认』的 ak- 串
```

**方式二 · HMAC-SHA256**（配置里 `auth_mode: "hmac"`，本项目默认）

```python
date = format_date_time(mktime(datetime.now().timetuple()))   # RFC1123 GMT
signature_origin = f"host: {host}\ndate: {date}\nGET {path} HTTP/1.1"
signature = base64(hmac_sha256(APISecret, signature_origin))
authorization_origin = (f'api_key="{APIKey}", algorithm="hmac-sha256", '
                        f'headers="host date request-line", signature="{signature}"')
url = f"wss://{host}{path}?" + urlencode({
    "authorization": base64(authorization_origin), "date": date, "host": host})
```

> 时间偏差须在 **300 秒**以内。

### 请求体（新版）

```json
{
  "header":    { "app_id": "...", "status": 2 },
  "parameter": { "oral": { "oral_level": "mid" },
                 "tts":  { "vcn": "x6_lingxiaoxuan_pro", "speed": 50, "volume": 50, "pitch": 50,
                           "audio": { "encoding": "lame", "sample_rate": 24000,
                                      "channels": 1, "bit_depth": 16, "frame_size": 0 } } },
  "payload":   { "text": { "encoding": "utf8", "compress": "raw", "format": "plain",
                           "status": 2, "seq": 0, "text": "<base64(文本)>" } }
}
```

- `status`：`0` 开始 / `1` 中间 / `2` 结束；**一次性传完直接传 `2`**（离线配音最稳）。
- 双向流式：同一会话可多次送文本（`0→1→…→2`），音频边合成边回。加 `--stream` 启用。
- 单会话文本总字节 **≤ 64K**；音频编码 `lame`=mp3 / `raw`=pcm，推荐 24000 Hz。

### 实用语法

| 写法 | 效果 |
|---|---|
| `你好[p500]科大讯飞` | 在「你好」后插入 **500ms 静音** |
| `着[=zhuo2]手` | 指定多音字读音（声调 1–5） |

> 配音卡口型时 `[pN]` 很有用——可以在句尾补静音凑够槽位时长。

### 常见错误码

| code | 含义 | 处理 |
|:--:|---|---|
| `11200` | 功能未授权 / 发音人未授权 | 控制台开通服务量**或**该发音人：https://console.xfyun.cn/services/uts |
| `10163` | 参数校验失败 | 多为 `vcn` 不在平台发音人白名单内 |
| `10313` | appid 与 apikey 不匹配 | 检查凭据 |
| `10222` | 文本超 64K 或 SSL 证书无效 | 拆分文本 |

| `_管线验证_timeline_18轨.mp4` | 18 轨精确对位验证（铺在 v9 41s 主片上；v12 未成片，故仅验证管线） |

**电平复核**（tl 输出）：无配音段 max −32.1 dB，配音段 max −3.9 dB —— 配音清晰突出、原声作为背景。

> **踩过的坑（已在脚本里修好，记录备查）：**
> 1. `atrim` 写在 `adelay` 之后 → 截掉的是 adelay 补的**前导静音**，整条配音变无声。**必须先 atrim 再 adelay**。
> 2. 单声道交给 `aformat=channel_layouts=stereo` 自动上混 → swresample 默认重矩阵给每声道乘 0.7071（**−3 dB**）。改用 `pan=stereo|c0=c0|c1=c0` 原地复制保持 0 dB。
> 3. `amix` 的 `normalize` 默认 `true`（按 1/N 衰减）。**必须显式写 `normalize=0`**，否则 18 轨混音直接掉 25 dB。

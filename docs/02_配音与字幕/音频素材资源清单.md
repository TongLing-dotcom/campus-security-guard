### 3. 版权合规要点

1. **优先选择 Mixkit 和 Pixabay** — 授权最简单，免署名、可商用、无后续费用
2. **使用前务必确认许可条款** — 每首曲子可能有不同许可
3. **CC0协议 = 最安全** — 放弃所有权利，可任意使用
4. **需署名的素材一定要在视频片尾标注** — 避免版权争议
5. **抖音/视频号平台检测** — 平台有音频指纹识别，使用正规无版权音乐可避免被限流
6. **避免使用热门流行歌曲** — 即使翻奏也容易触发版权检测

## 三、使用建议

### 反诈视频配乐节奏参考

| 视频段落 | 建议音乐情绪 | 推荐来源 |
|---------|-------------|---------|
| 开场·引出案例 | 神秘/悬疑 | Mixkit - Mysterious 分类 |
| 过程·诈骗展开 | 紧张/不安 | Mixkit - Crime / Thriller 分类 |
| 高潮·骗局揭露 | 戏剧性/调查感 | Mixkit - Investigation 分类 |
| 结尾·警示教育 | 沉思/正能量 | Mixkit - The Farewell 等反思类 |

### 下载与使用流程
1. 在 Mixkit / Pixabay 在线试听，筛选合适曲目
2. 直接下载 MP3 文件（无需注册）
3. 在剪辑软件（如剪映）中导入作为背景音轨
4. 调节音量至人声配音之下（建议 -15dB 至 -20dB）
5. 片尾如有需要，标注音乐来源（Mixkit/Pixabay 免署名可不标）

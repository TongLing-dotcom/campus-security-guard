**为什么不用 Apple「倒影 / Reflection」？**
Apple 的 iPhone 铃声（Reflection／Marimba 等）是 **Apple Inc. 的版权录音**，第三方站点分发的多为未授权副本。本项目立项时即定下红线——**字体与音乐一律只用无版权争议资源**，且短视频平台有音频指纹识别，用受版权保护的铃声存在被限流/下架的风险。因此铃声由本项目**原创合成**：与"iPhone 来电"的听感一致，但旋律与音色均为自制，可安全使用。

> 如你仍希望使用 Apple 原版铃声，请**自行取得授权版本**并把文件放入本目录，我可以直接换用（改一行路径即可），但授权责任需由提供方承担。

## 三、在成片中的用法

| 时间码 | 内容 | 相对电平 |
| :-- | :-- | :-- |
| 0:00.00–1.6s | BGM A 淡入 | 低（−6 dB 起） |
| 0:00–18.2s | BGM A · 悬念铺底（片头 ＋ 镜2） | **−6 dB**（自动音量曲线低档） |
| 18.2–20.2s | 音量平滑抬升（镜3 施压开始） | −6 dB → 0 dB |
| 20.2–34.2s | BGM A · 压迫（镜3 末 ＋ 镜4） | 0 dB（本轨基准） |
| 34.2–36.2s | A 淡出 ／ B 淡入（**交叉过渡**） | — |
| 35.542–37.708s | **电话铃声**（原创） | 峰值 −6 dB |
| 36.2–54.3s | BGM B · 温暖（镜7 真妈妈） | 0 dB（本轨基准） |
| 54.3–56.30s | BGM B 淡出收束 | — |

- **闪避（ducking）**：以「人声 ＋ 铃声」为触发信号，对 BGM 做 `sidechaincompress`（阈值 −30 dB / 压缩比 8:1 / 起振 15ms / 释放 600ms）——**有说话或铃声时 BGM 自动压低，安静段回升**。
- BGM 铺底整体 RMS 控制在 **约 −28 dBFS**（比人声低 20 dB 以上），确保台词清晰。
